# Morning brief feed

Sideline publishes a small data file every morning for your Claude morning brief.

| | URL |
|---|---|
| JSON (for the brief) | `https://<your-github-user>.github.io/<repo>/data/brief.json` |
| Markdown (human-readable) | `https://<your-github-user>.github.io/<repo>/data/brief.md` |
| Predictions, next 14 days | `https://<your-github-user>.github.io/<repo>/data/predictions.json` |

The brief is generated by `.github/workflows/brief.yml` (script: `scripts/build-brief.mjs`) and is
ready by **6:45 am Pacific** every day: normally around 4:50–5:50 am PT, with a backup run an hour
later. It builds on the nightly predictions (`.github/workflows/predictions.yml`, about 2 am PT) and
re-checks the latest betting lines when it runs. All times inside are **America/Los_Angeles**.

## Schema (`schema_version: 2`)

Version 2 adds pre-game predictions: a likely range, the chance of a Great game, Watch Priority,
and the `sleeper`, `skip` and `coming_up` sections. Every version 1 field keeps its meaning.

```jsonc
{
  "schema_version": 2,
  "generated_at": "2026-11-27T12:52:10.123Z",   // ISO 8601, UTC
  "generated_at_pt": "2026-11-27 4:52 AM PT",
  "timezone": "America/Los_Angeles",
  "date": "2026-11-27",           // the Pacific day the brief covers
  "replay_date": "2026-11-26",    // the day "worth_a_replay" looks at
  "scheduled": true,              // false when run by hand
  "engine_version": 3,            // post-game rating engine version
  "prediction_version": 1,        // pre-game prediction model version
  "predictions_date": "2026-11-27", // when the nightly predictions were made (null if missing)
  "app_url": "https://<user>.github.io/<repo>/",
  "window": {                     // games considered: 7 am today to 3 am tomorrow, Pacific
    "start": "2026-11-27T15:00:00.000Z", "end": "2026-11-28T11:00:00.000Z",
    "start_pt": "7:00 AM", "end_pt": "3:00 AM"
  },

  "top_games": [ Game ],          // top 5 by Watch Priority, at most 2 per league
  "favorites_today": [ Game ],    // every game your favorites play today (midnight to 3 am), by start time
  "sleeper": Game | null,         // highest chance of Great outside the top 5
  "skip": SkipGame | null,        // one high-profile game that projects Dull, with a warning
  "worth_a_replay": [ Game ],     // yesterday's finished games: all Great (85+) up to 8, else the top 5
  "coming_up": [ CircleItem ],    // new "Circle this one" flags since the last brief (up to 6)

  "counts": { "games_in_window": 38, "rated_in_window": 38, "finished_yesterday": 45, "rated_yesterday": 45 },
  "errors": []                    // data problems (an ESPN endpoint down, etc.); the brief still publishes
}
```

### `Game`

| Field | Example | Notes |
|---|---|---|
| `id` | `"nba:401810123"` | `<league>:<ESPN event id>` |
| `league` | `"NBA"` | short label; `league_key` is the internal key (`nba`, `epl`, `f1`, …) |
| `matchup` | `"Celtics at Lakers"` | soccer: `"Liverpool vs Everton"` (home first); F1: `"Qatar Grand Prix · Race"` |
| `home`, `away` | `"Los Angeles Lakers"` | `null` for F1 |
| `start_time_pt` | `"7:30 PM"` | Pacific; `start_iso` is the exact UTC time |
| `status` | `"scheduled"` | `scheduled`, `live`, `final` or `canceled`; `status_detail` has ESPN's text ("Q3 4:12", "FT") |
| `rating` | `74` | 0–100, or `null` when not rateable. Before the game this is **Predicted Excitement** (objective, no personal boosts) |
| `rating_state` | `"predicted"` | `predicted` (before the game), `live` or `final` |
| `band` | `"Good"` | `Dull` 0–39, `OK` 40–64, `Good` 65–84, `Great` 85–100 |
| `rating_low`, `rating_high` | `63`, `84` | predicted games: the likely range (middle 50% of outcomes for similar games) |
| `p_great`, `p_dull` | `0.22`, `0.04` | predicted games: chance it finishes Great (85+) / Dull (<40) |
| `horizon` | `"Prediction"` | `Prediction` (0–2 days out), `Forecast` (3–7), `Early look` (8–14) |
| `watch_priority` | `83` | ordering score: rating + 5 for your favorites + 0–4 star power. Never shown as a rating |
| `reason` | `"Coin-flip line (LAL −1.5) · Rivalry"` | one line, from the terms that moved the number most |
| `reasons` | `["Coin-flip line (LAL −1.5)", "Rivalry"]` | the same, as a list (up to 3) |
| `favorite` | `true` | involves one of your favorite teams; `favorite_team` names it (`"Lakers"`) |
| `watch` | `["ESPN (YouTube TV)"]` | only broadcasters reachable on your services (config/services.js) |
| `watch_summary` | `"ESPN (YouTube TV)"` | first option (a free stream reads `"Free on YouTube"` and comes first), or `"Not on your services"`, `"Not on your services (local TV)"` / `"No TV listing"` |
| `final_score` | `"Lakers 112, Celtics 110 (OT)"` | finished games only |
| `url` | `"https://…/#/game/nba/401810123"` | deep link into the app |

`SkipGame` is a `Game` plus `warning`, e.g. `"Lakers −14: blowout risk"`. A game is high-profile when it
involves a favorite or a star team, is on national TV, or has an AP top-10 college team; it projects Dull
when its predicted rating is under 40 or its chance of Dull is at least 35% (config/prediction.json `brief`).

### `CircleItem`

| Field | Example | Notes |
|---|---|---|
| `id` | `"nfl:401873120"` | |
| `league`, `league_key` | `"NFL"`, `"nfl"` | |
| `matchup` | `"Rams at 49ers"` | |
| `date`, `day_label` | `"2026-12-13"`, `"Sunday, December 13"` | Pacific |
| `start_time_pt`, `start_iso` | `"1:25 PM"` | |
| `reasons` | `["Two top-20% teams", "Big standings stakes"]` | a game is circled when two or more apply |
| `flagged_on` | `"2026-11-27"` | the night the flag first appeared |
| `url` | `"https://…/#/ahead"` | the Look Ahead tab |

Fields may be added in future versions; existing fields keep their meaning while
`schema_version` stays 2.

## Pointing your morning brief at it

Tell your brief something like: *"Fetch `https://<user>.github.io/<repo>/data/brief.json`. For the top
games give the predicted rating with its likely range, the chance of Great, start time, where to watch
and the reason. List every favorites game. Mention the sleeper, the skip warning if there is one,
anything in `worth_a_replay`, and new games to circle. If `date` isn't today in Pacific time, say the
sports feed is stale."*

## Also published

- `/data/predictions.json`: the nightly predictions behind the Look Ahead tab (every game in the next
  14 days with its prediction, range, chance of Great and inputs, plus circled games up to 60 days out).
  Optional leagues are listed schedule-only (`pred: null`). `offSeason` has one entry per league with
  nothing in the next 14 days: `{ "returns": "YYYY-MM-DD" | null, "preseason"?, "event"?, "inSeason"? }`.
- `/data/unmapped-networks.json`: broadcaster names ESPN listed that `config/services.js` doesn't map
  (days seen, leagues, markets, `youtubeLike`), written by the morning brief.
- The brief covers the core leagues. Optional leagues (Serie A, NASCAR, tennis, ...) are included only
  when `brief.includeOptional` is true in `config/prediction.json`, and then only those in
  `brief.optionalLeagues`, with the same 2-per-league cap. The WNBA is a core league.
- `/data/ratings/<YYYY-MM-DD>.json`: final ratings for every game of that day (last 14 days). The app
  uses these as a head start, so it doesn't refetch every finished game.
